# COVID-19: анализ поздних осложнений и метаболических последствий

Репозиторий с ноутбуками статистического анализа отдалённых (постковидных) исходов у пациентов,
перенёсших COVID-19 — по штаммам вируса (Ухань / Дельта / Омикрон) и по метаболическому профилю.
Материалы готовятся для научной публикации; итоговые отчёты выгружаются в markdown **без кода**
(только текст, таблицы и рисунки) для научного руководителя.

## Ноутбуки

| Ноутбук | Тема | Генератор | Данные |
|---|---|---|---|
| `covid_analysis.ipynb`, `covid_analysis_extended.ipynb` | Базовый анализ когорты (демография, тяжесть, лабораторные показатели) | — (собран вручную) | `initial_data.xlsx` |
| `covid_analysis_updated.ipynb`, `covid_analysis_extended_updated.ipynb` | Те же анализы на обновлённых данных (755 пациентов, добавлены столбцы осложнений) | `_build_copies.py` | `updated_data.xlsx` |
| `covid_complications.ipynb` | Поздние осложнения vs тяжесть (группы КТ), факторы риска, OR, логистическая регрессия и ML | `_build_complications.py` | `updated_data.xlsx` |
| `covid_metabolic.ipynb` | Динамика метаболизма за 24 месяца по штаммам (НОМА-IR, ИМТ, глюкоза, АЛТ, АСТ, ТГ, холестерин, фибриноген) | `_build_metabolic.py` | `data_v3.xlsx` |
| `covid_sd.ipynb` | Влияние метаболического синдрома (индекс TyG) на постковидные осложнения: OR-матрицы и случайный лес в двух группах, динамика TyG/HOMA-IR | `_build_sd.py` | `data_sd.xlsx` |

## Данные (`*.xlsx`)

| Файл | Назначение |
|---|---|
| `initial_data.xlsx` | Исходная выборка (базовый анализ) |
| `__initial_data.xlsx` | Архивная/ранняя версия исходных данных |

Данные и итоговые отчёты (`*.xlsx`, `*.md`, картинки) не хранятся в git — см. `.gitignore`.

## Как это устроено

Каждый анализ описан в скрипте-**генераторе** `_build_*.py`, который программно собирает `.ipynb`
из ячеек. Правки вносятся **в генератор**, а не в ноутбук напрямую. Типовой цикл:

```bash
# 1. окружение (один раз)
python -m venv .venv
source .venv/bin/activate
pip install pandas numpy scipy statsmodels scikit-learn matplotlib seaborn jupyter openpyxl

# 2. собрать ноутбук из генератора
python _build_sd.py

# 3. выполнить ноутбук «на месте»
jupyter nbconvert --to notebook --execute --inplace covid_sd.ipynb

# 4. выгрузить отчёт для руководителя: без кода, картинки внешними файлами
jupyter nbconvert --to markdown --no-input --output covid_sd covid_sd.ipynb
```

Шаг 4 создаёт `covid_sd.md` и папку `covid_sd_files/` с рисунками (без base64-вставок).

`_build_copies.py` — служебный: переносит базовые ноутбуки на `updated_data.xlsx`, прозрачно
подменяя имена листов, поэтому остальной код не меняется.

## Соглашения

- **Правим генераторы, а не ноутбуки.** Ноутбук — производный артефакт (перегенерируется скриптом).
- **Экспорт для руководителя — без кода** (`--no-input`) и с **внешними** картинками (без base64).
- **Все зависимости — в venv** (`.venv`).
- Базовые `covid_analysis*` собраны вручную и не имеют генератора — их не перезаписывать скриптами.
